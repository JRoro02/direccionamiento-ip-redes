# Direccionamiento IP y Diseño de Redes

Proyecto del ciclo de ASIR sobre direccionamiento IPv4 (clases de red, 
cálculo de subredes y hosts) y diseño práctico de una red multi-oficina 
simulada en Cisco Packet Tracer.

📄 [Memoria completa (teoría + capturas)](DIRECCIONAMIENTO.docx)
🖥️ [Simulación de red (Cisco Packet Tracer)](trabajo%20redes.pkt)

## 📚 Contenido teórico
- Clases de direcciones IPv4 (A, B, C, D, E) y sus rangos
- Cálculo de número de redes y hosts por clase
- Identificación de octetos de red/host según la clase
- Cálculo de rangos válidos de host en una subred (ejercicio con /28)

## 🌐 Diseño de red práctico
Simulación de una red corporativa con **3 oficinas** interconectadas:
- Configuración de routers, switches y access points
- Direccionamiento IP estático en PCs, portátiles e impresoras de red
- Conexión inalámbrica (WiFi) mediante tarjetas de red y access points
- Interconexión de oficinas y configuración del protocolo de enrutamiento **RIP**
- Verificación de conectividad extremo a extremo

## 🛠️ Herramientas y tecnologías
`Cisco Packet Tracer` `IPv4` `Subnetting` `RIP` `Redes WiFi`

> Para abrir el archivo `.pkt` necesitas tener instalado [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer) (gratuito con cuenta de Cisco Networking Academy).
